# @pipelex/sdk — moved

This repository is archived. `@pipelex/sdk`, the TypeScript client for the Pipelex hosted API, now lives in the `js/` directory of [Pipelex/pipelex-sdk](https://github.com/Pipelex/pipelex-sdk/tree/main/js), beside its Python twin, the starters and the method-app templates.

The package keeps its name and is published to npm from there. The last version released from this repository was 0.28.1, and every later version comes from `Pipelex/pipelex-sdk`.

- **npm:** [`@pipelex/sdk`](https://www.npmjs.com/package/@pipelex/sdk)
- **Source:** [`js/` in Pipelex/pipelex-sdk](https://github.com/Pipelex/pipelex-sdk/tree/main/js)
- **Issues and pull requests:** [Pipelex/pipelex-sdk](https://github.com/Pipelex/pipelex-sdk/issues)
